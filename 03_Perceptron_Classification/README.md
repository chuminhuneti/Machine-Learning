# 03. Perceptron Classification – Mô hình Perceptron

## 1. Giới thiệu

Perceptron là một trong những mô hình học máy đầu tiên được phát triển cho bài toán phân loại. Đây là mô hình phân loại tuyến tính, sử dụng một hàm quyết định để phân chia không gian đặc trưng thành các vùng tương ứng với các lớp.

Chương này tập trung vào nguyên lý xây dựng mô hình Perceptron và quá trình huấn luyện thông qua hàm mất mát và quy tắc cập nhật tham số.

## 2. Mục tiêu học tập

Sau khi hoàn thành chương này, sinh viên có thể:

- Hiểu cách xây dựng mô hình phân loại Perceptron từ dữ liệu.
- Xác định và tính toán hàm mất mát của mô hình.
- Hiểu cách tính gradient và ý nghĩa của gradient trong huấn luyện.
- Trình bày và thực hiện thuật toán Gradient Descent.
- Sử dụng Python để huấn luyện và đánh giá mô hình phân loại Perceptron.
