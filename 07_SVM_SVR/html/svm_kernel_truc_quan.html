120 mẫu huấn luyện + 60 mẫu kiểm tra, hai vòng tròn có nhiễu. Hàng: γ = 0,1 / 1 / 50. Cột: C = 0,1 / 1 / 100. Mỗi ô được huấn luyện đến hội tụ bằng SMO. Số liệu sinh lại nên không trùng tuyệt đối với bảng trong tài liệu, nhưng xu hướng thì giống.

Đồi Gauss: f(x) = Σ αᵢyᵢ·k(xᵢ, x) + b

Tóm tắt: nhớ ba dòng này là đủ
Kernel: k(x, z) = φ(x)φ(z)ᵀ. Thay xᵢxⱼᵀ trong dạng đối ngẫu bằng k(xᵢ, xⱼ): Qᵢⱼ = yᵢyⱼ·Kᵢⱼ. Bài toán vẫn chỉ có n biến.
Huấn luyện: max 1ᵀα − ½αᵀQα, với yᵀα = 0, 0 ≤ α ≤ C. SMO mỗi lần chọn một cặp (i, j) vi phạm KKT nhiều nhất và giải đúng bài toán hai biến.
Dự đoán: f(x) = Σ αᵢyᵢ·k(xᵢ, x) + b, chỉ cộng qua vector hỗ trợ. RBF: γ lớn → đồi hẹp, dễ quá khớp; γ nhỏ → trơn, dễ dưới khớp.
