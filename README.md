# MACHINE LEARNING – HỌC MÁY

Repository lưu trữ tài liệu giảng dạy, bài giảng và Notebook thực hành học phần **Machine Learning (Học máy)** dành cho sinh viên ngành Khoa học dữ liệu.

## 1. Mục tiêu học phần

Giúp sinh viên nắm vững nguyên lý xây dựng và huấn luyện các mô hình học máy cơ bản, hiểu vai trò của mô hình, hàm mất mát và thuật toán tối ưu; đồng thời biết triển khai, thực nghiệm và đánh giá mô hình bằng Python.

## 2. Nội dung học tập


| STT | Chủ đề | Nội dung |
|---|---|---|
| 01 | [Tổng quan Học máy](01_Tong_quan_Hoc_may/) | Khái niệm, phân loại và quy trình học máy |
| 02 | [Linear Regression](02_Linear_Regression/) | Hồi quy tuyến tính và các thuật toán tối ưu |
| 03 | [Perceptron Classification](03_Perceptron_Classification/) | Mô hình Perceptron và phân loại tuyến tính |
| 04 | [Logistic Regression](04_Logistic_Regression/) | Phân loại nhị phân và dự đoán xác suất |
| 05 | [Softmax Regression](05_Softmax_Regression/) | Phân loại đa lớp |
| 06 | [Artificial Neural Networks](06_Artificial_Neural_Networks/) | Mạng nơ ron nhân tạo và thuật toán lan truyền ngược |
| 07 | [SVM/SVR](07_SVM_SVR/) | Máy vector hỗ trợ cho bài toán phân loại và hồi quy |
