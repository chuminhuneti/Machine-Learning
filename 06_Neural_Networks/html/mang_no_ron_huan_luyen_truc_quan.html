Xem mạng nơ-ron học

Bấm Huấn luyện và quan sát: vùng quyết định thay đổi, đường cong mất mát đi xuống, các trọng số đổi màu. Mọi thứ chạy ngay trong trình duyệt, không cần cài gì.

1. Chọn bài toán và mạng

Gợi ý: đặt số lớp ẩn = 0 trên XOR hoặc xoắn ốc để thấy Softmax Regression (mô hình tuyến tính) thất bại; rồi tăng lên 1 và 2 lớp ẩn. Đổi sang sigmoid với 3 lớp ẩn để thấy gradient biến mất.

2. Vùng quyết định

lớp 0lớp 1lớp 2 Chấm đặc: tập huấn luyện. Vòng rỗng: tập kiểm định (mạng không được học trên các điểm này). Màu nền càng đậm thì mạng càng tự tin.

3. Đường cong học

Trên: mất mát J (cross-entropy). Dưới: độ chính xác. Nét liền là huấn luyện, nét đứt là kiểm định.

4. Mạng đang nghĩ gì

epoch 0J huấn luyện: –J kiểm định: –đúng (huấn luyện): –đúng (kiểm định): –tham số: –
Bấm “Huấn luyện” để bắt đầu.

Sơ đồ mạng. Đường xanh: trọng số dương; đường cam: trọng số âm; càng dày thì |trọng số| càng lớn. Xem chúng đổi màu khi học.

Chuẩn gradient theo lớp (mini-batch gần nhất)

Nếu thanh của các lớp đầu ngắn hơn rất nhiều so với lớp cuối, đó là gradient biến mất (mục 4.3). Thử sigmoid với 3 lớp ẩn, rồi đổi sang ReLU.

5. Đọc những gì bạn thấy

  • Vùng quyết định thẳng, J đứng yên cao (ví dụ 0 lớp ẩn trên XOR): mô hình quá đơn giản, thiên lệch cao. Thêm lớp ẩn.
  • Giai đoạn phẳng rồi đột ngột giảm: mạng đang rời cao nguyên (điểm yên ngựa) gần khởi tạo, như Hình 14 của giáo trình.
  • J huấn luyện giảm nhưng J kiểm định tăng lại: quá khớp. Thử tăng λ, giảm số nơ-ron, hoặc dừng sớm.
  • Chạy lại nhiều lần với cùng cấu hình sẽ cho kết quả hơi khác: hàm mất mát không lồi nên kết quả phụ thuộc khởi tạo.
  • η quá lớn (gần 1) với SGD làm J dao động; η quá nhỏ làm J giảm rất chậm.

6. Giải thích những đoạn mã khó

Toàn bộ mạng nằm trong phần <script> ở cuối file này (khoảng 250 dòng). Bốn đoạn dễ gây khó khăn nhất:

a) Softmax ổn định số học 
function softmaxRow(z){
  const m = Math.max(...z);              // trừ giá trị lớn nhất của hàng
  const e = z.map(v => Math.exp(v - m)); // số mũ lớn nhất bằng e^0 = 1, không tràn
  const s = e.reduce((a,b) => a+b, 0);
  return e.map(v => v / s);
}

Công thức pk = ezk / Σ ezj sẽ tràn số nếu z lớn (e1000). Softmax không đổi khi trừ cùng một hằng số khỏi mọi zk (tử và mẫu cùng nhân e−m), nên ta trừ giá trị lớn nhất.

b) Trọng số có hàng bias ở đầu 
// W[l] có (vào + 1) hàng × (ra) cột. Hàng 0 là bias.
let s = W[0][j];                        // bias của nơ-ron j
for (let i = 0; i < vao; i++) s += a[i] * W[i+1][j];  // tổng có trọng số

Cách này tương đương việc thêm một đầu vào luôn bằng 1 (ký hiệu Ã trong giáo trình), nhờ đó bias được cập nhật bằng cùng công thức gradient như mọi trọng số khác.

c) Lan truyền ngược: đi lùi từng lớp 
// D là sai số tại lớp ra: D = (P − Y) / n  (softmax + cross-entropy)
for (let l = L-1; l >= 0; l--) {
  G[l] = Ã[l]ᵀ · D            // gradient của W[l]: (vào+1) × (ra)
  if (l > 0) {
    // chuyển lỗi về lớp trước: nhân với W bỏ hàng bias, rồi nhân từng phần tử với φ′
    D = (D · W[l] bỏ hàng 0 ᵀ) ⊙ φ′(Z[l-1])
  }

Ý nghĩa: lỗi ở lớp sau được phân bổ về từng nơ-ron lớp trước theo trọng số nối (phép nhân ma trận), rồi bị cổng φ′ chặn lại nếu nơ-ron bão hòa (φ′ ≈ 0). Chính phép nhân φ′ lặp lại qua nhiều lớp gây ra gradient biến mất với sigmoid.

d) Adam: vì sao có hai “bộ nhớ” m và v 
m = b1*m + (1-b1)*g;          // trung bình trượt của gradient (hướng đi, như momentum)
v = b2*v + (1-b2)*g*g;        // trung bình trượt của g² (độ lớn điển hình)
mh = m/(1-b1^t); vh = v/(1-b2^t);  // hiệu chỉnh độ chệch những bước đầu (m, v bắt đầu từ 0)
w -= eta * mh / (Math.sqrt(vh) + 1e-8);

Mỗi trọng số tự có “tốc độ học riêng”: gradient luôn nhỏ thì chia cho căn v nhỏ nên bước đi được phóng to; gradient dao động mạnh thì bước đi được thu nhỏ.
